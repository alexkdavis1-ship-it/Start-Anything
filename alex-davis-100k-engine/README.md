# Alex Davis · 100K Follower Viral Content Engine

Built 2026-11-16. All external metrics are from the vidIQ outlier index on that date.

| File | What it is |
|---|---|
| `00_executive_recommendation.md` | Start here. The 10 videos to film first, the decisions made, and what could not be done |
| `01_creator_audit.md` | Your Instagram, TikTok and YouTube history with direct links, findings and coverage gaps |
| `02_viral_reference_database.csv` | 742 researched candidate videos (all 1M+ views): URL, views, creator median, outlier multiple, hook, format, and whether the footage was reviewed |
| `03_production_masterlist.md` | All 50 videos ranked by the weighted rubric, with score breakdowns |
| `04_filming_scripts.md` | All 50 complete filming scripts in production order |
| `05_measurement_growth_model_and_trial_rules.md` | Growth scenarios, Trial Reel settings, the replacement for the 10K rule, weekly iteration loop |
| `06_trial_reel_tracker.csv` | One row per video with formulas for follows per 1,000 reached, shares per 1,000 and watch % |
| `07_seven_day_production_calendar.md` | Daily assignments, setups, props, collaborators and workload |
| `scripts/V001.json` to `V050.json` | Each video in the requested JSON schema |
| `scripts/draft/` | Build inputs, keyed by research reference |
| `research/` | Verbatim walkthroughs of the 63 watched reference videos, and the merged candidate file |
| `build.py` | Regenerates files 02, 03, 04, 06, 07 and the final JSON from `scripts/draft/` |

Video IDs are in production order (grouped by location). Priority rank is separate and is shown in every file.
